# Blurify

A glass, HyperOS-style volume bar for Android (9 and newer), with an optional control center (Android 12 and newer). No root needed.

Download: https://blurify.houseli.site

Made by Houssam, TikTok [@mituhype](https://www.tiktok.com/@mituhype).
